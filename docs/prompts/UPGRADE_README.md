## 四条不可违背的铁律

1. **先查资料，别空想**——基于论文/旗舰实践/自己的数学推导，禁止拍脑袋。
2. **一切必须真实、可证明、是一个整体**——禁止 mock/伪造/硬编码；每个创新必须有严格数学证明；全项目同步升级；引擎不接入其他模型。
3. **交付真实权重**——权重上 HF + ModelScope，源码上 Gitee + GitHub（不含权重），没交付就不许停。
4. **诚实优先于达标**——能达标必须达标；确实不可达必须诚实报告 + 给出证明 + 继续死磕其余部分；**严禁伪造达标**（见 `UPGRADE_01_ROLE.md`「诚实原则与失败报告」）。

## 关键机制（务必掌握，否则会跑偏）

- **查算分离**：314B = 628 个 0.5B 知识块，每次稀疏激活 ~0.5B；**它是模型自身权重，不是外部数据库**；寻址/存储/调取/注入/训练隔离**无现成方案，是你必须自主发明的核心创新**（`UPGRADE_03_ARCH.md` 3.2）。
- **模态 = 4 种**（text/image/audio/video）；document 与 agent **不再是独立模态**（agent 回归文本层面工具调用）。
- **指标分层**：P0（底线，必达）→ P1（核心评测，死磕到达标）→ P2（尽力而为 + 诚实报告差距）（`UPGRADE_09_METRICS.md`）。
- **Fermi 前置**：动手前先做量级核算，确认 T4 + 可用资源下指标物理可达（`UPGRADE_10_DELIVER.md` 阶段 0 第 7 步）。
- **禁止项转检查脚本**：所有"禁止"都要有可运行的检测（`UPGRADE_06_CODING.md` 6.8）。

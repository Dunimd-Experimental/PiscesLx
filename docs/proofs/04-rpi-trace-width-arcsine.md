# 证明 4：RPI 轨迹宽度的反正弦定律 τ(k,d) = (2/π)·arcsin(√(k/d))

对应实现：`model/config.py::YvConfig.__post_init__`（`block_trace_dim` 的反解）、
`model/core/block_field.py::paired_initialize`、`model/core/block_addresser.py`。

本证明回答一个问题：**共振配对初始化（RPI）到底需要多宽的轨迹 `k`。**
它不是调参，而是由一条定律反解出来的。

---

## 0. 记号与前提假设

- 主干隐维 `d = hidden_size`；轨迹宽 `k = block_trace_dim`；`k ≤ d`。
- 寻址投影 `W ∈ R^{k×d}`（`YvResonantTraceAddresser.query_proj` 的转置视角），
  行满秩，其行空间 `S = row(W)` 是 `R^d` 的一个 `k` 维子空间。
- `P := Wᵀ(WWᵀ)⁺W` —— 到 `S` 的**正交投影**（对称幂等：`P² = P = Pᵀ`，`rank P = k`）。
- `u_i ∈ R^d`：第 `i` 个知识块的"贡献方向"（RPI 从块内容算出的代表向量，见证明 0）。
- `h ∈ R^d`：一次查询的隐状态。

**(A1) 高斯各向同性。** `h` 在比较的两个块上近似各向同性零均值高斯：
`h ~ N(0, σ²I_d)`。依据：主干 LayerNorm 后各向同性是标准近似；本证明的结论只用到
`h` 的分布正交不变，不用到具体 σ。

**(A2) 投影子随机且与 `h` 独立。** `W` 的 `k` 行独立同分布高斯 ⇒ `S` 是 `Gr(k,d)` 上
的**Haar 均匀**随机子空间，且与 `h` 独立。（初始化期成立；训练中 `W` 被更新，
本证明给的是**初始化对齐度**，即 RPI 生效那一刻的保序性，这正是它要解决的问题。）

**(A3) 方向非退化。** 比较的一对块满足 `u_i ≠ u_j`。

---

## 1. RPI 恒等式：打分 = 投影后的打分

RPI 的构造（`paired_initialize`）为
`R_i = (ρ/rms)·Wᵀ(WWᵀ)⁺ u_i`，故寻址打分

```
⟨W h, R_i⟩ = (ρ/rms)·⟨W h, Wᵀ(WWᵀ)⁺ u_i⟩
           = (ρ/rms)·⟨h, Wᵀ(WWᵀ)⁺W u_i⟩        （转置伴随）
           = (ρ/rms)·⟨h, P u_i⟩.                 （P 的定义）
```

**(引理 1)** 全局常数 `(ρ/rms)` 与块号 `i` 无关 ⇒ 它**不改变排序**。因此
"按轨迹 `R_i` 打分"与"按投影方向 `P u_i` 打分"给出**完全相同**的块序。

> 这一步把问题从"RPI 写出来的码本好不好"化归为一个纯几何问题：
> **正交投影 `P` 在多大程度上保持内积比较的符号？**

---

## 2. 单对翻转概率 = 二维高斯的符号一致率

固定一对 `(i,j)`，令 `a := u_i − u_j ≠ 0`（A3）。两个打分差为

```
Δ_pre  := ⟨h, u_i⟩ − ⟨h, u_j⟩ = ⟨h, a⟩,
Δ_post := ⟨h, P u_i⟩ − ⟨h, P u_j⟩ = ⟨h, P a⟩      （P 线性、对称）
```

这一对发生翻转 ⟺ `sign(Δ_pre) ≠ sign(Δ_post)`。

由 (A1)(A2)，`(Δ_pre, Δ_post)` 是联合零均值高斯。给定 `P`：

| 量 | 值 | 依据 |
|---|---|---|
| `Var(Δ_pre)` | `σ²‖a²` | `h ~ N(0,σ²I)` |
| `Var(Δ_post)` | `σ²‖Pa‖²` | 同上，`‖P‖_F` 无关，只需幂等：`Var(⟨h,Pa⟩)=σ²‖Pa‖²` |
| `Cov` | `σ²⟨a, Pa⟩ = σ²‖Pa²` | `P² = P = Pᵨ ⇒ ⟨a,Pa⟩ = ⟨Pa,Pa⟩` |

故相关系数

```
ρ := Corr(Δ_pre, Δ_post) = ‖Pa‖² / (‖a‖·‖Pa‖) = ‖Pa‖ / ‖a‖ =: cos θ,   (2.1)
```

其中 `θ` 是 `a` 与子空间 `S` 的夹角。**投影只通过夹角影响符号一致率。**

**(引理 2, Shepp/反正弦律)** 对任意联合零均值高斯 `(X,Y)` 相关 `ρ`：

```
P[XY > 0] = 1/2 + (1/π)·arcsin(ρ).
```

*推导*：`(X,Y)` 落在第一或第三象限。由旋转不变性，命中概率 = 对应扇形角度 / `2π`；
椭圆等高线经 Cholesky 线性变换映到圆，象限边界映成两条过原点的直线，其夹角余弦为 `ρ`，
故半角为 `arcsin(ρ)`；两象限合计 `2·(π/2 + arcsin ρ)/2π`。∎

于是给定 `P`（即给定 `ρ`）：

```
P[不翻转 | P] = 1/2 + (1/π)·arcsin(‖Pa‖/‖a‖).                     (2.2)
```

---

## 3. 随机子空间里的 `‖Pa‖/‖a‖`：Beta 分布与集中

**(引理 3)** 设 `S` 为 `Gr(k,d)` 上 Haar 随机子空间（A2），固定单位向量 `e`。则

```
Z := ‖P_S e‖² ~ Beta(k/2, (d−k)/2),     E[Z] = k/d,   Var[Z] = (k/d)(1−k/d) / (d/2 + 1).
```

*推导*：取正交阵 `Q` 使 `S = span(Q e_1..e_k)`；Haar 性 ⇒ `Qe` 均匀分布于单位球 `S^{d−1}`
（与 `e` 无关，此即 `O(d)` 表示在球上的唯一不变测度）。故 `‖P_S e‖² = Σ_{i=1..k} ξ_i²`，
其中 `ξ = Qe ∈ S^{d−1}` 均匀。标准结论：球面均匀点的前 `k` 个坐标平方和服从
`Beta(k/2,(d−k)/2)`（等价地由 `g/‖g‖`、`g ~ N(0,I_d)` 化为 `χ²_k/(χ²_k + χ²_{d−k})`）。
均值方差即 Beta 的矩。∎

由 (3)，`Var[Z] = Θ(1/d) → 0`，且 `Z` 以 `O(d^{-1/2})` 阶集中（Beta 尾为 sub-Gaussian，
或直接 `P(|Z − k/d| ≥ t) ≤ 2exp(−d t²/4)` 由球集中不等式）。故 `ρ = √Z` 也集中在 `√(k/d)`：

```
E[ρ] = B((k+1)/2, (d−k)/2) / B(k/2, (d−k)/2) = √(k/d) · (1 + O(1/d)),   ρ = √(k/d) + O_p(d^{-1/2}).  (3.1)
```

---

## 4. 定理：保序度的渐近式

Kendall `τ` 的定义是"随机一对在两个排序下不一致的概率 `n_s` 与一致概率 `n_c` 之差"：
`τ = n_c − n_s = 2·P[不翻转] − 1`。对 (2.2) 关于 `S` 取期望，并用 `arcsin` 的 Lipschitz 性
（`|arcsin x − arcsin y| ≤ |x − y|/√(1−max(x,y)²)`，在 `k/d ≤ 1−ε` 时有界）吸收 (3.1) 的涨落：

**定理 1（反正弦定律）** 设 (A1)–(A3) 成立，`k/d` 有界离于 `1`。则 RPI 初始化后
轨迹打分对块内容排序的 Kendall 保序度为

```
        τ(k, d) = (2/π)·arcsin(√(k/d)) + O(d^{-1/2}).
```

`k/d → 1` 时由 `ρ → 1`（此时 `P = I`，见推论 2）取极限，公式仍给出 `τ → 1`。∎

**反解（宽度选择法则）** 要求 `τ ≥ τ₀` 的最小宽度是

```
        k = d · sin²(π τ₀ / 2).                              (4.1)
```

`model/config.py` 实现的正是 (4.1)，并对 `k ≤ d` 与 `k ≥ 8` 做钳位：

```python
tau   = min(max(self.block_alignment_target, 0.0), 1.0)
width = self.hidden_size * math.sin(0.5 * math.pi * tau) ** 2
self.block_trace_dim = max(8, min(self.hidden_size, int(math.ceil(width))))
```

## 5. 与实测的对照（本机 CPU，`tools/test/test_sbf_paired_init_contract.py`）

| `k/d` | 定理 1 预测 `τ` | 实测 Kendall `τ` | 相对误差 |
|---|---|---|---|
| `1`（`k = d`） | 1.000 | **1.000** | 0% |
| `1/8` | 0.2301 | **0.227** | 1.3% |
| `0.0625`（旧固定 `k=256`, `d=4096`） | 0.161 | ≈0.11–0.16 | 同量级 |
| `0.6545`（`τ₀=0.6` 反解，`d=4096` ⇒ `k=2681`） | 0.6000 | **0.613** | 2.2% |

`O(d^{-1/2})` 修正项在 `d=256~4096` 下约为 `0.02~0.06`，与观测到的偏差同量级：
定理的**主项在真实维度上就是对的**，不是渐近摆设。

## 6. 推论

**推论 1（旧常量在旗舰尺度必然失效）** 固定 `k = 256` 与 `d` 无关。`d = 4096` 时
`k/d = 1/16` ⇒ `τ = (2/π)arcsin(1/4) = 0.162`；`d` 越大越差。RPI 写下的码本
**只保留约 16% 的内容排序信息**，等价于"配对初始化几乎没做"。
这就是把 `k` 从常量改为由 `d` 推导的原因（`docs/audit/00` 登记为 A68）。

**推论 2（`k = d` 时 RPI 精确，不只是保序）** `k = d` 且 `W` 可逆 ⇒ `P = Wᵀ(WWᵀ)⁻¹W = I_d`，
引理 1 的恒等式变成 `⟨Wh, R_i⟩ = (ρ/rms)⟨h, u_i⟩`：投影**完全消失**，
轨迹打分与真实内容打分至多差一个全局正因子，`τ ≡ 1`（无需概率论证）。
此时 `ρ` 在 (2.1) 中为 `1`，与定理 1 的边界一致。

**推论 3（宽度不是延迟瓶颈）** 寻址每 token 的代价是 `O(d·k + n·k)`（一次查询投影 +
与 `n` 条轨迹打分）。取 `k = d`、`d = 4096`、`n = 628`：`16.8M + 2.6M ≈ 19.4M` MAC，
对 7B 主干每 token 约 `14G` FLOP 的占比为 `1.4e-3`。地址器是**全局单件**（一份
`query_proj` + 一份 `n×k` 码本），不随块数复制，也**不计入块体积**
`block_size_params`，因此提高 `τ₀` 不会破坏"314B = 628×0.5B"的池容量律（见证明 0 §容量）。

> **工程结论**：`τ₀` 是"保序度 vs 寻址常数开销"的唯一旋钮，默认取 `0.60`
> （`k/d ≈ 0.6545`）作为**下界**；由推论 2–3，旗舰档把 `block_alignment_target`
> 推到 `1.0` 在算式上是有利的（`k = d`、RPI 精确、开销 <0.2%），
> 但需先以 P1 的"知识块调取 ≤5ms/token"实测确认，故**不在此处默认上调**。

## 7. 假设失效时会发生什么（诚实边界）

- **(A1) 不成立**（`h` 强各向异性，例如被少数主方向支配）：`ρ` 不再是 `‖Pa‖/‖a‖`，
  而取决于 `a` 在主方向集中的程度。若 `a` 恰落在 `S` 内则不翻转（更好），
  若垂直则必然翻转（更差）。定理给的是各向同性期望，不保证逐对。
- **(A2) 训练中失效**：`W` 被梯度更新，`S` 不再 Haar 均匀。本定理只约束
  **第 0 步**的对齐质量 —— 这恰是 RPI 的全部职责（给寻址一个正确的起点），
  之后的对齐由 `block_addresser` 的残差/陈旧度机制负责，不在此声明范围。
- **有限样本**：`n = 628` 条轨迹 ⇒ Kendall 统计量的标准误约 `√(var/n_pairs)`，
  表中 2% 上下的偏差部分来自此，与 `O(d^{-1/2})` 修正同向。

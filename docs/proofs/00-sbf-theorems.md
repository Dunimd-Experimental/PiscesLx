## 引理 0（整块同步搬运不可行）

**命题**：在带宽 `W_host = 12 GB/s` 的主机↔设备通道上，若每 token 需从主机搬运一整块
（FP16，体积 `V = 2P` 字节），则单 token 搬运耗时 `T_x = V / W_host` 超出预算 `B_ms`，
故不存在满足 `B_ms` 的同步搬运方案。

**证明**：
```
V = 2 × 5×10⁸ B = 1.0 GB          （依据：FP16 = 2 字节/参数）
T_x = 1.0 GB ÷ 12 GB/s = 83.3 ms   （依据：速率定义 T = 体积/带宽）
B_ms = 5 ms                          （依据：UPGRADE_09_METRICS.md 表 9.3）
T_x / B_ms = 16.7 > 1                 ∎
```
**必要性论证（为何量化也救不了）**：令块以 `b` 位/参数存储，则体积 `V = P·b/8`，
```
T_x(b) = (P·b/8) / W_host = (5×10⁸ · b/8) / (12×10⁹) s = 5.2·b ms
要求 T_x ≤ 5 ms ⇒ b ≤ 0.96 位/参数
```
即**必须把每参数压缩到不足 1 bit**。而知识块需承载可用知识（`UPGRADE_02_MISSION.md` 3.2 要求
"知识足够有知识"），0.96 bit/参数 远低于任何可用的语义保真度（率失真意义下的可行码率下界远高于此）。
故"靠量化把整块塞进 5 ms"被排除。∎

> **意义**：本引理排除了一整类"每 token 取一块"的天真设计，迫使设计满足
> **块已在设备上** 或 **搬运代价被摊薄**（见定理 2）。这是设计 §0.1 的直接依据。

## 定理 1（寻址开销与块计算量的分离，即"查算分离"的计算论基础）

**命题**：RTA 的单 token 寻址计算量为 `O(N·k)`，被选中块的应用量为 `O(P)`，二者比值
```
O(N·k) / O(P) = (628 × 256) / (5×10⁸) = 3.2×10⁻⁴
```
因此寻址开销约为块计算的 0.032%，可忽略；且总计算量相对"稠密启用全部 314B"下降 `N` 倍。

**证明**：
1. 打分：对全部 `N` 块计算 `⟨q, r_i⟩`，每块 `k` 次乘加 ⇒ `F_addr = N·k = 1.608×10⁵` FLOPs（依据：内积定义）。
   等价的矩阵形式为一次 `[N×k]·[k]` 乘积，故可按 GPU 批量完成，访存 `628×256×2 B = 0.32 MB`。
2. 块应用：块参数 `P = 5×10⁸`，其前向至少为一次稠密/低秩作用，`F_blk = Ω(P)`（依据：对 P 个参数各做一次乘加）。
3. 比值：`F_addr / F_blk = 1.608×10⁵ / 5×10⁸ = 3.2×10⁻⁴`。
4. 稀疏比：全启用为 `N·P`，本设计为 `P + O(N·k)`，故
```
(N·P) / P = N = 628
```
   即每 token 计算量降低 628 倍，同时保留 314B 的等效可访问容量。∎

**正确性（低维投影是否引入误差）**：RTA 用 `k` 维痕迹而非 `P` 维全参数做寻址。设真理想用的
块选择为 `i* = argmax_i ⟨q, ρ_i⟩`（`ρ_i` 为块 i 的"理想高维检索子"，`ρ_i ∈ R^{D}`，`D = P`），
实际用 `r_i = Proj(qspace) ρ_i`。依据 Johnson–Lindenstrauss 引理（已知结论：随机投影保持点对距离，
`k = O(ε⁻² log N)` 时失真 ≤ ε），取 `k = 256`、`N = 628` 时 `ε ≈ √(log N / k) = √(6.44/256) = 0.159`。
于是打分相对误差有界，`argmax` 在**间隙大于 2ε** 时选择一致；否则两块的共振近于等价，
选择差异对输出的影响由定理 5 的相对扰动界吸收。**该近似位置与误差界在此显式声明，非隐藏假设。**

## 定理 2（切换率上界 ⇔ 最小驻留下界）—— 滞回寻址的必要性

**设定**：把 token 流上"块切换"看作更新过程：相邻两次换块之间的间隔（驻留长度）为 i.i.d. 随机变量
`X`，`E[X] = D`；每次换块产生一次异步搬运，代价 `T_x`（引理 0 的 83.3 ms）。

**命题**：若搬运可完全与主干计算重叠（§4 的异步设计），则**每 token 摊薄搬运时间**为
```
E[摊薄时间/token] = T_x / D = T_x · p ,  其中 p = 1/D
```
要满足预算 `B_ms`，必须
```
p ≤ B_ms / T_x = 5 / 83.3 = 0.060   ⇔   D ≥ 16.7 token
```

**证明**：由**更新报酬定理**（renewal–reward theorem，已知结论：对更新过程，
长-run 平均报酬 = `E[单周期报酬] / E[单周期长度]`）：
- 单周期长度 = `X`（一个驻留段内的 token 数），`E[X] = D`；
- 单周期报酬 = 该周期发生的搬运时间 = `T_x`（每次换块恰一次搬运，依据 §4 步 4 的去重规则）；
- 故长-run 每 token 摊薄搬运 = `T_x / D`。代入 `D = 1/p` 得 `T_x·p`。
- 解不等式 `T_x·p ≤ B_ms` 得 `p ≤ 0.060`，等价 `D ≥ 16.7`。∎

**推论（为何滞回项是必需的，而非调参偏好）**：若无滞回、纯按瞬时打分选块，
`i_t` 仅由 `h_t` 决定，而 `h_t` 逐 token 变化，经验上切换率接近 1（`p → 1`），
则 `T_x·p = 83.3 ms/token ≫ 5 ms`，**违反定理 2 的必要条件**。因此打分函数必须包含
跨 token 的耦合项 `−λ(1 − δ_{i,i_{t-1}})`，把 `p` 压到 0.06 以下。∎

**与表 9.3 的一致性**：`B_ms = 5 ms` 正是 `UPGRADE_09_METRICS.md` 表 9.3
「314B 知识块池激活/调取延迟 ≤ 5 ms/token」。**本设计满足该指标，且给出了它可被满足的充要条件**
（时间局部性假设：真实语料上 `D ≥ 16.7`）。该假设列为待验证（设计 §9），不可假装成立。

### 推论 2.1（驻留下界由构造保证，而非依赖语料性质）

定理 2 给出的是**必要条件** `D ≥ T_x/B_ms`。实现进一步强化为**充分可控**：
寻址器对逐 token 的 `argmax` 序列施加**游程平滑**（run-length smoothing），
任何短于 `min_dwell` 的游程并入其较长邻域，因此**选择序列中不可能出现短游程**。

- **终止性**：每次合并消去一个游程且新游程长度 = 两者之和 ≥ 被消去者，
  游程数严格递减 ⇒ 至多 `T/1` 步收敛；结束时若仍有短游程，则整行长度 < `min_dwell`（平凡情形）。
- **宽度不变**：合并只重标块号，不增删 token，`selected.shape[1] == T` 恒成立。
- **代价**：当话题切换确实快于 `min_dwell` 时，平滑会**强制选中次优块**。
  这不是免费的：它把「调取延迟可行」与「选块最优」之间的张力，从"祈祷语料局部性"
  转化为**可量化的近似误差**。该误差由定理 5 的相对界 `κ` 约束（误取块至多弱化主干 `κ` 比例），
  但**任务准确率的影响仍须实测**（见 §7 待实证项 1 的修订）。∎

**实现绑定**：`model/core/block_addresser.py::YvResonantTraceAddresser.apply_dwell_constraint`
（`_run_encode` / `_merge_short_runs` / `_run_decode`）。
**回归**：`tools/test/test_sbf_mechanism.py::check_dwell_floor_is_constructive`，
6 种 (floor, T) 组合含 `T < floor` 边界，断言最短游程 ≥ 下界且宽度不变 —— **实测通过**。

## 定理 3（寻址信息经济学：容量线性增长，寻址开销仅对数增长）

**命题**：每 token 的寻址决策至多传递 `log₂ N` bit；可访问的存储容量为 `N·P·8` bit。
二者比值
```
R_cap = (N·P·8) / log₂ N = (628 × 5×10⁸ × 8) / 9.295 = 2.70×10¹¹
```
若把容量按因子 `m` 扩张（块数变为 `mN`），寻址开销仅增 `log₂(mN) − log₂ N = log₂ m` bit（对数），
而可访问容量线性增 `m` 倍。

**证明**：
1. 每 token 的寻址输出是 `{1,…,N}` 中的一个索引，其熵 `H(i_t) ≤ log₂ N = 9.295 bit`
   （依据：离散分布熵在均匀分布时取最大 `log₂ N`）。
2. 块池总存储位（FP16）`C_bits = N·P·8? `—— 每参数 16 bit，故 `C_bits = N·P·16`；
   本文按"参数量 × 位/参数"的两种口径都列出：以 `2 字节/参数` 计 `C_bits = N·P·16 = 5.02×10¹² bit`。
3. 比值 `C_bits / H_max = 5.02×10¹² / 9.295 = 5.4×10¹¹`（以 8 bit/参数 口径则为 `2.70×10¹¹`；
   本文取保守的 8 bit 口径以免高估）。
4. 扩张因子 `m` 的微分：`d(log₂(mN)) = dm/(m ln2)` 而 `d(mNP) = NP·dm`，
   故容量每增 1% 需付寻址位 `≈ 0.0143 bit/token`（`log₂(1.01) = 0.0143`）。∎

**有效性（这正是"查"侧的意义）**：主干每 token 只付出个位数 bit 的"选择"代价，
就换取了对千亿亿 bit 级自有权重的访问。对比稠密模型：知识必须**编码进权重本身**并靠
前向计算隐式展开，其访问代价与容量同阶（定理 1 的 `N·P` 全算）。
本设计把"访问代价"与"容量"解耦为 **对数 vs 线性** 关系——这是查算分离的形式优势，不是口号。

**边界声明（不过度声称）**：本定理是**计数/复杂度**结论，不是"知识内容容量"的信息论定理。
块里能否真正存住可用知识，取决于写入质量（训练隔离，定理 6）与检索正确率（定理 1 的 JL 界），
属经验问题，由表 9.2「查算分离后 MMLU 提升 ≥8 分」实测裁决。

## 定理 4（异步阶梯调取的阻塞时间与陈旧度界）

**设定**：§4 的策略规定未命中时**继续用驻留池中上一个有效块计算**，目标块后台搬运，
到达后替换空槽。定义"陈旧度"为块生效相对寻址决策滞后的 token 数。

**命题**：
(a) **无阻塞**：每 token 设备侧关键路径不含 `T_x`，故推理时间不含 83.3 ms 项；
(b) **陈旧度 ≤ 1 个 token**（对"最新决策"而言）；
(c) 摊薄搬运代价满足定理 2。

**证明**：
(a) 主干第 `t` 步的输出只依赖 `h_t` 与**已在设备上**的块（驻留池成员），
    搬运在独立 CUDA stream 上执行、不参与该步的依赖图 ⇒ 关键路径长度不含搬运时间
    （依据：流并行的依赖图语义；无数据依赖的 kernel 不进入关键路径）。
(b) 第 `t` 步决策出 `i_t`；若未命中，`t+1` 步仍使用旧块，块在 `t + T_x/token_time` 之后到达并
    自该步起生效。故"决策与实际作用之间最多错开一个（旧块作用的）token"，
    即作用序列相对决策序列滞后 ≤ 1 token。
(c) 每次换块恰触发一次搬运（§4 步 4 的取消规则保证去重），
    周期结构满足定理 2 的更新过程假设 ⇒ 摊薄 = `T_x·p`。∎

**必要性（为何可以容忍滞后）**：滞后带来的误差由定理 5 的相对扰动界控制——
旧块的作用幅度同样受 `κ‖h‖` 约束，因此"迟一步"与"错一步"的劣化同阶且有界，不存在失控放大。

## 定理 5（乘性注入的相对扰动界、Lipschitz 性与梯度稳定性）

**注入形式**（设计 §5）：
```
Δh = α (γ ⊙ h + β),   h' = h + Δh
```
**假设 A1**：块的调制头有界：`‖γ‖_∞ ≤ γ_max`，且 `‖β‖ ≤ c‖h‖`
（实现要求：`β` 由归一化头产出，例如 `β = W_B σ(N(h))`，`‖W_B‖₂ ≤ c`，`‖N(h)‖ ≤ ‖h‖`；
`N` 为 RMSNorm —— 依据：RMSNorm 输出范数 ≤ 输入范数 × 权重谱范数）。

**命题 5.1（相对扰动界）**：在 A1 下
```
‖Δh‖ ≤ α (γ_max ‖h‖ + c‖h‖) = κ ‖h‖,   κ := α(γ_max + c)
‖h'‖ ≤ (1 + κ)‖h‖,   ‖h'‖ ≥ (1 − κ)‖h‖
```
**证明**：`‖γ ⊙ h‖ ≤ ‖γ‖_∞‖h‖`（逐元素积的范数不等式，依据：`‖a⊙b‖_2 ≤ ‖a‖_∞‖b‖_2`）；
`‖β‖ ≤ c‖h‖` 由 A1；三角不等式给出 `‖Δh‖ ≤ α(γ_max + c)‖h‖`。
再对 `h' = h + Δh` 用三角不等式两次，得上下界。∎

**命题 5.2（Lipschitz 性与梯度有界）**：设块作用映射 `Φ: h ↦ h + α(γ(h) ⊙ h + β(h))`，
`γ(·), β(·)` 均为 `L_γ, L_β`-Lipschitz。则 `Φ` 为 `1 + α(L_γ‖h‖ + γ_max + L_β)`-Lipschitz，
其雅可比奇异值上界有限，故**梯度不会因块误取而爆炸**：对 `L` 层堆叠，
```
‖∂loss/∂h_0‖ ≤ Π_{l}(1 + κ_l)'  … 有界量
```
（依据：链式法则 + 谱范数次乘性 `‖AB‖₂ ≤ ‖A‖₂‖B‖₂`）。
因此 `UPGRADE_09_METRICS.md` 表 9.2「梯度范数维持在 [0.1, 10.0]」在本机制下**不因换块而破坏**。

**命题 5.3（加性专家不具备 5.1 的相对界 ⇒ 必须用乘性）**：考虑加性形式 `h' = h + E_i(h)`。
取 `E_i(h) = v`（与 `h` 无关的常向量，`‖v‖ = M`），则
```
‖h' − h‖ / ‖h‖ = M / ‖h‖ → ∞  当 ‖h‖ → 0
```
即**相对扰动无上界**，误取一块可以把输出完全掀掉。乘性形式在 A1 下相对界为 `κ`（与 `‖h‖` 无关），
**取错块只会"少帮忙"，不会"帮倒忙"**。这就是注入形式选择的证明级依据，而非风格偏好。∎

**实现绑定**：`dual_injector.py` 的调制头必须实现 A1（归一化 + 谱范数约束），
否则定理 5 的前提不成立；该项列为数值回归测试（设计 §8-7）。

**实现注记（9.7.1「数值稳定性」要求的落实）**：`β` 的归一化分母必须是**加性** `‖x‖ + ε`，
而非 `clamp_min(‖x‖, ε)`。后者在 `‖x‖ → 0` 处等价于 `x/‖x‖`，其导数**不存在**，
实测会在反向传播中产生 **NaN 梯度**（本项目在 `model/core/block_field.py` 的实现过程中真实遇到并修复）。
采用加性分母后：
1. `‖β‖ = c‖h‖·‖x‖/(‖x‖+ε) < c‖h‖` —— A1(ii) 仍然成立（界甚至更紧）；
2. 映射处处光滑，梯度有限 —— 由 `check_grad_finite` 断言实测（`‖∂L/∂h‖ = 11.31`，非 NaN）。∎

## 定理 6（有界陈旧度下的下降引理 —— ABGB 的收敛依据）

**设定**：块只在驻留池期间被更新（块级串行落格），其优化器状态陈旧度以已处理 token 数计为 `τ`。

**假设 B1**：单块损失 `ℓ_i(θ)` 对 θ 为 `L`-光滑，梯度方差有界 `E‖g̃‖² ≤ σ²`，
学习率 `η ≤ 1/L`。

**命题**：在 `τ`-陈旧梯度下，一步更新的期望下降满足
```
E[ℓ_i(θ_{t+1})] ≤ E[ℓ_i(θ_t)] − (η/2)‖∇ℓ_i(θ_t)‖² + (η³L²τ²·G²)   （陈旧偏差项）
```
即**陈旧度只带来与 `η³L²τ²G²` 同阶的可控偏差**，不破坏下降性；当 `τ` 有界时仍收敛到
一阶平稳点的邻域（邻域半径随 `τ → 0` 消失）。

**证明思路（自包含推导，不依赖未声明的外部结论）**：
1. `L`-光滑 ⇒ `ℓ(y) ≤ ℓ(x) + ⟨∇ℓ(x), y−x⟩ + (L/2)‖y−x‖²`（光滑性定义，标准下降引理）。
2. 代入 `y = x − η g̃`，取期望，交叉项 `−η‖∇ℓ‖² + (η²L/2)E‖g̃‖²`。
3. 分解 `g̃ = ∇ℓ(θ_{t−τ}) + ξ`（ξ 为随机噪声），
   `‖∇ℓ(θ_{t−τ}) − ∇ℓ(θ_t)‖ ≤ L‖θ_{t−τ} − θ_t‖ ≤ L·η·τ·G`（用 Lipschitz 梯度 + 每步位移 ≤ ηG 累加 τ 次）。
4. 该项产生的额外下降损失 ≤ `(η L² τ² G²)/2`；对 τ 次更新求和即得偏差项量级 `O(η³L²τ²G²)`。
5. 取 `η ≤ 1/L` 使二次项不超过线性下降项的一半 ⇒ 结论。∎

**由此导出 ABGB 第 2 项（陈旧动量重置）的阈值选取**：
令偏差项 ≤ 下降主项的 1/10，即 `η³L²τ²G² ≤ (η/20)‖∇ℓ‖²`，得
```
τ ≤ sqrt( ‖∇ℓ‖² / (10 η² L² G²) )
```
→ `tau_staleness` **不是拍脑袋常数**，而由当前梯度范数、`L`（可用幂迭代估计谱范数）、
`η`、`G` 代入算出，作为配置项写入 `YvConfig`（满足禁硬编码）。

**为何"未激活块梯度恰为零"不构成矛盾**：定理 6 是**逐块**的下降陈述；未入选块在该步不受更新，
其目标函数在该步的梯度**本就为零**（未被使用 ⇒ 无梯度通路），
不属于"被冻结"。定理 6 只对**被激活的块**陈述收敛，与
`UPGRADE_03_ARCH.md` 3.2「被激活的知识块参与训练」严格一致。

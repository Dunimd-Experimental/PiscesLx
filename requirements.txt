# =============================================================================
# PiscesLx Installation Order (Optimized for pip - No Redownload)
# =============================================================================
# Key principles:
# 1. Install PyTorch FIRST with exact versions
# 2. Then packages that depend on specific torch version
# 3. Then everything else
# 4. Use --no-deps for packages with known good transitive dependencies
# =============================================================================
#
# !!! COMPATIBILITY MATRIX (DO NOT LOOSEN WITHOUT TESTING) !!!
#   transformers  : >=4.45.0, <4.46          (keeps PreTrainedModel at top level)
#   tokenizers    : >=0.20.0,  <1.0
#   huggingface-hub: >=0.25.0, <1.0
#   modelscope    : ==1.27.0                (1.x line that matches transformers 4.45.x)
#   datasets      : >=3.0.0,   <4.0         (datasets 4.x has API breakage)
#
# `modelscope.msdatasets.MsDataset` does `from transformers import PreTrainedModel`
# at import time. That symbol was removed from the top-level `transformers`
# namespace in `transformers >= 4.46`. If you bump the transformers cap, you
# will get:
#     ModuleNotFoundError: Could not import module 'PreTrainedModel'.
#     Are this object's requirements defined correctly?
# when the PiscesLx data downloader tries to load ModelScope-hosted datasets.
# Do not change any of the above ranges without also re-testing
# `python manage.py download`.
#
# IMPORTANT NOTES FOR WINDOWS USERS:
# =============================================================================
# 1. flash-attn: Requires compilation, may take 10-30 minutes
#    - If fails: pip install flash-attn --no-build-isolation
#    - Or skip: PiscesLx will use PyTorch's native attention
#
# 2. triton: Not fully supported on Windows
#    - Automatically skipped on Windows (platform_system=="Linux")
#    - PiscesLx will work without it
#
# 3. mamba-ssm & causal-conv1d: Require CUDA compilation
#    - If fails: PiscesLx will fall back to standard attention
#    - Ensure CUDA toolkit is installed and in PATH
#
# 4. bitsandbytes: May require Visual Studio Build Tools
#    - If fails: pip install bitsandbytes-windows
#
# QUICK INSTALL (Recommended):
# pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
# pip install -r requirements.txt --no-deps
# pip install -r requirements.txt
#
# =============================================================================

# Primary mirror (Tsinghua, fast in China) for most packages.
# Use --extra-index-url for PyPI fallback on packages that Tsinghua mirror
# only has as source distribution (pre-built CUDA wheels).
# pip prefers wheels over source distributions, so PyPI will provide
# flash-attn, mamba-ssm, causal-conv1d as pre-compiled wheels.
--index-url https://pypi.tuna.tsinghua.edu.cn/simple
--extra-index-url https://pypi.org/simple

# PiscesL1 Installation Order (Optimized for pip - No Redownload)
# =============================================================================
# Key principles:
# 1. Install PyTorch FIRST with exact versions
# 2. Then packages that depend on specific torch version
# 3. Then everything else
# 4. Use --no-deps for packages with known good transitive dependencies
# =============================================================================
# 
# IMPORTANT NOTES FOR WINDOWS USERS:
# =============================================================================
# 1. flash-attn: Requires compilation, may take 10-30 minutes
#    - If fails: pip install flash-attn --no-build-isolation
#    - Or skip: PiscesL1 will use PyTorch's native attention
#
# 2. triton: Not fully supported on Windows
#    - Automatically skipped on Windows (platform_system=="Linux")
#    - PiscesL1 will work without it
#
# 3. mamba-ssm & causal-conv1d: Require CUDA compilation
#    - If fails: PiscesL1 will fall back to standard attention
#    - Ensure CUDA toolkit is installed and in PATH
#
# 4. bitsandbytes: May require Visual Studio Build Tools
#    - If fails: pip install bitsandbytes-windows
#
# QUICK INSTALL (Recommended):
# pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
# pip install -r requirements.txt --no-deps
# pip install -r requirements.txt
#
# =============================================================================
